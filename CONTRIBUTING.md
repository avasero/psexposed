# 🤝 How to Contribute to PSExposed

his guide will help you submit new PowerShell security indicators for the community.

## 🚀 Ways to Contribute

### 1. 📝 Submit New Indicators

**Via Pull Request:**
1. Fork the repository
2. Create a branch: `git checkout -b new-indicator-[name]`
3. Add your file to the `indicators/` folder
4. Submit a Pull Request

### 2. 🐛 Report Issues

If you found a problem with an existing indicator, or a suggestion, etc:
1. Open issue
2. Describe the problem in detail
3. Include examples when possible

## 🙏 Acknowledgments

The creators and maintainers of indicators are also listed at the [powershell.exposed](https://powershell.exposed/indicators) website.
