# powershell.exposed - Chrome Extension!

Google Chrome extension for analyzing PowerShell scripts directly from your browser.

## Installation

1. Download the extension from the GITHUB repository and load it manually in developer mode at chrome://extensions.
2. After installation, the extension icon will appear in the Chrome toolbar.

## Initial Setup

1. Click on the extension icon to open it
2. Go to [www.powershell.exposed/settings](https://www.powershell.exposed/settings) to generate your **API Key**
3. Copy the generated API Key
4. Paste the API Key into the extension's input field
5. Save the configuration

## How to Use

There are two ways to analyze PowerShell scripts:

### Option 1: Analyze in the Extension

1. Select the text (PowerShell code) with your mouse on any web page
2. **Right-click** on the selected text
3. Select **"Quick Analyze"**
4. The analysis will be processed and displayed directly in the extension
5. After the analysis, you can view the full report on the website

### Option 2: Analyze on the Website

1. Select the text (PowerShell code) with your mouse on any web page
2. **Right-click** on the selected text
3. Select **"Open in WebApp"**
4. A new tab will open on the website with the complete analysis

## Flow Summary

| Method | Where analysis is performed | Result |
|--------|----------------------------|--------|
| Analyze with PowerShell.Exposed | In the extension | Quick view + report on site |
| Analyze with PowerShell.Exposed on site | On the website | Full analysis directly on site |
